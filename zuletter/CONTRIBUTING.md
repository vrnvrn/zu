# Contributing to ZuLetter

Thanks for your interest in contributing to the Zuzalu community newsletter!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```

## Making Changes

1. Create a new branch from `main`:
   ```bash
   git checkout -b your-branch-name
   ```
2. Make your changes
3. Test locally to make sure everything works
4. Commit your changes with a clear message
5. Push to your fork and open a Pull Request

## Newsletter Content

If you're submitting updates for a hub or pop-up city, please include:

- Hub name and dates
- A short description (keep the tone consistent with existing entries)
- Any relevant links
- Images (place in `public/newsletters/images/`)

## Code Style

- This is a Next.js project using TypeScript
- Follow the existing patterns in the codebase
- Keep changes focused and minimal
